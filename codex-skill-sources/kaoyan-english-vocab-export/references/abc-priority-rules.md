# A/B/C Output Rules

Classify only items supported by the verified article, frozen conversation packages,
or a ready sentence-support record whose exact package evidence pointer revalidates.
An older support projection is routing evidence only when a newer current package for
the same episode exists.

A: affects comprehension, question logic, contrast, cause, condition, concession or attitude; explicit unknown/mistranslation; familiar-word-new-meaning; high-transfer phrase.

B: stable reading or writing value but lower priority.

C: low-priority recognition, background vocabulary, proper names or low-transfer items.

Exclude currently mastered items using the effective formal review ledger; a later recorded reactivation supersedes older proof without deleting that proof. Mark existing bank matches and duplicates. A same-sense bank match reuses and displays its existing bank ID as this article's occurrence; do not remove it merely because it is already in the bank. A different sense requires exact article evidence. Missing source text becomes needs_context. A/B/C is output priority, not formal write authority.
