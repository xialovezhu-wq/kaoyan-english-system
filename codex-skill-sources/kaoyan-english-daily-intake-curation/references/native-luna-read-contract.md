# Native Read-Leaf Contract

This contract applies only inside an authorized through-cutoff formal-curation turn and only after one daily manifest has been frozen.

The current parent owns semantic decisions and the deterministic writer. An Ultra root uses its selected engineering model and supported native proactive orchestration; this contract does not impose a model, effort, fork mode, service tier or worker count. An explicit current user request for Luna is honored only in its stated scope. A leaf is read-only, cannot delegate and returns evidence to the same parent.

Each leaf receives only the frozen package hashes, allowed package and processing-library roots, one concrete query and required return fields. It may read source-backed identities, existing bank matches, sentence-pattern matches or duplicate evidence. It cannot write packages, formal files, indexes, receipts or archives; allocate IDs; emit authoritative typed actions; or authorize apply.

Use leaves only for useful independent reads. Consolidate every started leaf, reject scope drift, mutation, missing hashes or incomplete returns, and keep the decision with the parent after a leaf failure. Do not activate another processing pipeline.

Ultra uses native proactive orchestration without the orchestrate Skill. Non-Ultra must read and use the existing orchestrate Skill before deciding whether the independent read split is worthwhile.
