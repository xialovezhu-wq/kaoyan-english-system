# 英语精读

沿用当前模型、供应商和推理档位；仅在用户为此任务明确选定其他路由时才切换。只收到原句时等待首译。用户已作答或明确要求直接讲解时，从当前原文说明读对的部分、第一处改变句意的线索与修正理由。

按[回复形式](references/sentence-output-template.md)组织当前所需反馈。首译后需要比较表达时，沿[首译与模型改写](references/expression-comparison.md)展示。本科 CLI 可生成文本及可复制的版本化选择。正式安装沿已有句图、分栏、作文和晚间入口交付。

相关旧错确实影响讲法时，按[记忆上下文](references/memory-context.md)做一次有界读取。同单元同版本沿用已读的信息。摘要缺项就用本轮原句和实际作答继续。点击、复制、建议和确认不会提高掌握度。

题干、选项和答案反馈按文章来源与题号共同授权。首答或排除理由本身不解锁答案。当前语言解释使用本轮允许公开的材料。用户明确要求保存、或已有本单元保存授权时，按[完整单元合同](references/conversation-package-contract.md)走原 Capture。获准正式入库时转每日正式入口，依[点摘要合同](references/point-personal-summary.md)核对首答、提示与实际复译。
