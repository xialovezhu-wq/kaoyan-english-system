# 考研英语学习系统

面向英语精读、翻译纠偏、词汇与句型积累的本地证据流水线。系统将一次完整学习单元的保存，与正式词库、句型库、个人摘要和复习状态的更新分开，使讲解、保存和掌握证据可以被清楚追溯。

## 运行逻辑

1. 精读以当前原句和真实翻译为依据，按涉及的词、句型、选项或错误点查询一次已有个人摘要。查询未命中时直接依据当前作答讲解，不扩大为全历史检索。
2. 用户明确要求保存时，`capture_current_english.py` 按会话与消息边界封存完整原句、段落或题目单元、原始附件及真实对话。独立单元不需要修复旧续传链。
3. 快速 Capture 不评分、不更新个人摘要或正式库。`english_web_workflow.py` 负责未完成学习包的网页准备与回包流程。
4. 正式处理使用 typed actions 和唯一写者：核对来源、原始日期、哈希、权限与幂等关系后，更新词库、句型库和正式学习状态。
5. 个人摘要只在正式入库时更新；归档、展示资产、后续发布与词汇导出使用各自的完整性回执。失败恢复不应重复正式 apply。

## 目录

| 目录 | 用途 |
|---|---|
| `english_pipeline/` | Capture、不可变包、正式写者、个人摘要、网页回流、归档与恢复 |
| `scripts/` | 当前学习单元入口、总 CLI、网页工作流、词汇导出及资料预处理 |
| `schema/english_pipeline/` | Capture、对话包、typed actions、正式事务、回执和摘要结构 |
| `codex-skill-sources/` | 精读、快速保存、网页打包、正式入库和导出技能合同 |
| `tests/`、`examples/` | 合成测试子集、无个人数据的结构示例 |

私有运行时的 `bank/`、`articles/`、`review/`、`raw/`、`intake/`、`wiki/` 保存使用者自己的资料与学习记录。仓库仅公开处理这些目录的逻辑，不附带其内容。

## 环境与入口

建议 Python 3.11 及以上。核心包主要使用标准库；部分 PDF/图像资料预处理需要 Poppler 命令行工具和 Pillow，Swift OCR 需要 macOS。Codex 会话库、外部归档、Obsidian、共享发布器和模型配置由使用者自行准备。

在仓库根目录可只读查看接口：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 scripts/capture_current_english.py --help
PYTHONDONTWRITEBYTECODE=1 python3 scripts/english_learning_pipeline.py --help
PYTHONDONTWRITEBYTECODE=1 python3 scripts/english_web_workflow.py --help
```

完整运行前须准备自己的私有数据目录，显式指定 `--repo-root` 以及入口需要的状态路径、会话身份和消息边界。正式 writer 需要完整 schema 与可核验原始证据；不能将本仓库的合成示例冒充个人作答。

## 公开范围与个人数据边界

本仓库从本地学习系统单独导出，只包含通用源码、数据结构、当前工作流合同和少量合成测试。原仓库的 Git 历史没有迁入。

真实题卡、首次作答、完整对话、个人知识点摘要、复习记录、分数、调度状态、Capture 包、原始附件、书籍教材和外部归档均不公开。`examples/` 是本次专门编写的合成结构示例，不能作为真实学习证据提交。

源码中的本机用户路径已改为 `/Users/your-user`；归档磁盘 UUID 改为全零占位；原账号的私有库名称不作为默认远端。涉及 Study-Pro-Bridge、Obsidian、MarginNote、Codex 会话库和外部磁盘的集成功能需要使用者自行配置。不要把真实学习目录直接作为这个公开仓库的工作目录。

公开版未携带个人生产绑定描述符，需要在自己的隔离环境生成对应绑定；历史迁移脚本的个人修复清单已清空，保留通用实现。技能文件是工作流参考，不会自动安装或执行。原系统的旧协议保留用于理解和恢复逻辑，不能替代下文所列当前入口。

## 验证情况

发布准备进行了全部 Python 文件的 `ast.parse` 语法检查、全部 JSON 文件解析、下列入口的 `--help` 检查及 Gitleaks 源码扫描。没有执行真实学习写入、正式入库、归档或云端发布；没有运行需要完整私有库与外部应用的端到端流程。

`tests/` 仅保留已检查为临时目录和合成数据的测试子集；没有宣称完整测试套件通过。

## 公开版的发布边界

本公开副本不默认向原三科完整私库上传。原账号远端已替换为 `YOUR_GITHUB_ACCOUNT` 占位，本机集成路径已替换为 `/Users/your-user`，生产共享发布器和私有运行配置没有打包进入此仓库。上面的 `--help` 命令只显示接口，不执行学习写入或上传。后续若自行接入发布器，须先明确设置自己的目标目录、远端和公开范围；公开源码仓库与真实学习数据目录应分别维护。
