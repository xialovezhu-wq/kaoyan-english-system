# 英语项目生产提示的脱敏审阅映射

精读用 [kaoyan-english-intensive-reading](../codex-skill-sources/kaoyan-english-intensive-reading/SKILL.md)，保存用完整 Capture，正式入库走每日 author 和唯一 writer。当前模型与用户指定的任务路由由宿主提供。这个审阅映射保存跨入口的稳定规则；当轮的文章版本、句号、阶段和可公开的检索结果由当前工具调用提供。

只收到原句时等待用户首译。用户明确要直接讲解时按其范围答复。文章与题号共同限制答案反馈。以原句、真实首译、后续用户修订和提示顺序为证据，按需展示[表达对照](../codex-skill-sources/kaoyan-english-intensive-reading/references/expression-comparison.md)。模型建议只用于展示，实际教学记忆由已授权的真实原件与正式写者更新。
